# bir-motier
نظام إدارة بئر محمد أحمد مطير | Water Well Management System لإدارة المشتركين والعدادات والقراءات والفواتير والمدفوعات والمتأخرات وأصحاب الوايتات والتقارير. مبني بـ Next.js وTypeScript وSupabase PostgreSQL، مع Arabic RTL, RBAC, RLS, Billing, Payments, Reports, Authentication وأمان متكامل.
